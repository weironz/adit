# #230 远程 VNC 字体重影的取样器修复验收

被测基线 `c9e3074`（修复前），修复后的工作树。缺陷：远程 VNC 界面显示的字体
有重影不够清晰。

## 根因

远端桌面纹理每块只绘制一次，然后缩放到面板，所以决定取样器的是**纹理放大倍数**
（源纹素到设备像素）。演示缩放是 `display_scale / fit`，而面板每逻辑点有
`display_scale` 个设备像素，两者相消——放大倍数正好等于 fit 系数：1.0 是一设备
像素对一个远端像素，适应窗口时是 `fit` 个设备像素对一个远端像素。

最近邻取样**复制**纹素而不是重采样。只有放大倍数是整数时它才在整幅画面上均匀：
放大 1.2367 倍时，一根 1 像素的笔画在有些地方落在一个屏幕像素上，在有些地方落在
两个上，于是文字看起来被画了两遍——这就是重影。

报告者的场景里面板 1908 像素宽、源 1792 像素宽，fit 系数 1908/1792 = 1.0647，
正是一个分数。

修复后的规则：**整数放大倍数（≥1）用最近邻，其余用线性重采样**。1:1 的桌面保留
它一直用的最近邻（整数放大，重采样不会更清晰，只会让所有远端桌面变软）。

## 验收方法

验收不看代码分支，只看合成器截下来的像素。夹具
[`native_rfb_fixture.py`](../../native_rfb_fixture.py) 以 `ADIT_FIXTURE_TEXT=1`
在 1200×800 的帧缓冲上用 GDI ClearType 画一段真实文本——**字形在源分辨率下只
光栅化一次**，帧缓冲里已经是成品字形像素，由客户端决定如何放大。这正是缺陷描述
的情形。

采集由 `vnc_native_acceptance` 示例程序完成：`ADIT_NATIVE_CAPTURE=1` 时先在
「适应窗口」下截一张，再切到「原始比例」截一张 1:1 对照。事件日志记录了窗口
尺寸、曲面尺寸、fit 系数和合成器缩放。

两次运行几何完全一致：窗口 1500×1100，曲面 1200×800，合成器缩放 1.0，
放大倍数 1.2366666793823242，1:1 对照正好 1.0。

### 判定一：颜色集合

最近邻复制纹素，所以它画出的每个颜色都已经是帧缓冲里的像素；重采样会混合邻居，
于是造出帧缓冲里从未有过的颜色。帧缓冲的颜色集合**由夹具本身算出**，不依赖任何
一次渲染。

| 采集 | 文本区不同颜色数 | 其中帧缓冲里没有的 |
| --- | --- | --- |
| 1:1 源（对照） | 54 | 0 |
| 适应窗口，最近邻（修复前） | 54 | 0 |
| 适应窗口，重采样（修复后） | 5871 | 5869 |

### 判定二：被复制了一遍的笔画

最近邻把一个源列映射到 ceil(f) 或 floor(f) 个设备列，所以在分数放大倍数下，
一部分设备列与它左边那一列逐字节相同。重采样每列都造一个新值，所以几乎没有。
**被复制的那一列就是笔画被画了两遍**——也就是报告的重影。

| 采集 | 有笔画的列 | 其中被复制的 | 比例 |
| --- | --- | --- | --- |
| 1:1 源（对照） | 230 | 0 | 0 |
| 适应窗口，最近邻（修复前） | 286 | 55 | 0.19231 |
| 适应窗口，重采样（修复后） | 286 | 0 | 0 |

### 判定三：1:1 对照必须逐像素不变

修复只影响分数放大倍数。1:1 的对照图在两个二进制之间相差 **199 像素**，位置
x 465..493、y 1082..1089——**在曲面之下**（1:1 的曲面到 y 970 为止），落在状态栏
里，而状态栏带的是会话自己的文字。同一个二进制跑两遍相差 **583 像素**，在同一
位置。曲面本身在 1:1 下逐像素相同。

### 不依赖对齐的交叉验证

整幅曲面上重复列的比例（不定位任何东西，直接量）：源 0.77481、最近邻 0.77073、
重采样 0.73163；整幅曲面的不同颜色数 58 / 272 / 6495。

## 这次验收不证明什么

- 这是合成器截屏上的测量，证明**客户端如何放大远端桌面**；不证明服务端编码、
  JPEG 画质或远端字体的清晰度。
- 合成 RFB peer 不是厂商服务端，不证明任何厂商的 VNC 实现的兼容性。
- 1:1 对照的 199 像素差异是状态栏的会话文字，不是采样器。
- 报告者原始截图的边缘扫描线比例 0.140（左侧 1200 像素）/ 0.108（全图），
  落在最近邻的区间（×1.146 时 0.137、×1.2365 时 0.232），而原生 ClearType 在
  1:1 下是 0.0042、线性放大在各系数下都是 0.005–0.011。这一条是独立的旁证，
  不属于上面的判定。
