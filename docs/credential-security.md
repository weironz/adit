# 凭据库格式、迁移与恢复边界

本文说明可选主密码的实现与操作边界。开发验收状态以 [#214](https://github.com/weironz/adit/issues/214) 为准；本文不是发布声明。

## 两种模式

- v1 兼容模式使用程序中的公开内置输入派生密钥。这只能混淆磁盘内容，不能抵御获得程序和凭据文件的攻击者。继续保留此模式用于兼容旧版本，不将它称为主密码保护。
- v2 主密码模式使用用户输入，通过 Argon2id v1.3（64 MiB、3 次、并行度 1，16 字节随机盐，32 字节输出）派生密钥，再用 XChaCha20-Poly1305 加密。每次写入使用系统随机数生成独立 nonce。
- 文件包含固定 KDF 配置标记和加密校验项，不包含主密码。v2 条目的 AEAD 附加数据绑定账号标识，交换两个账号的密文会验证失败。读到未知版本、错误保护标记、损坏数据或验证失败时拒绝处理；v2 不尝试内置密钥回退。

SSH 登录密码、私钥口令、RDP/VNC 密码以及同步令牌都通过同一存储接口按账号隔离。迁移不会改变配置中的 profile ID。

## 用户操作

设置 → 应用中提供读取状态、启用、解锁、锁定、修改、关闭主密码保护、导出和导入。新主密码至少 12 个 Unicode 字符；两次输入必须一致。Argon2 和文件操作由工作线程执行。

每次进程启动时 v2 处于锁定状态。解锁会验证校验项和所有已存条目，再允许读取。锁定会清除共享缓存中的派生密钥，所有由该 CredentialStore 克隆出的句柄同时生效。修改或关闭保护仍需要当前主密码。关闭设置会清除主密码输入框。

锁定约束的是后续存储读取，不会主动断开已有 SSH/RDP/VNC 会话。运行中的连接和自动重连可能保留已经取出的认证信息；这些连接副本不会因锁定凭据库而撤销。操作系统管理员、进程内存读取、键盘记录和被控制的本机不在此磁盘加密的防护范围内。普通连接表单和部分现有连接 API 仍使用 String；不能承诺整个进程没有明文副本或交换文件残留。

## 迁移与原子写入

1. 读取完整旧库并验证其格式和解密结果。
2. 在内存中生成新盐和候选库，对每一条候选密文进行解密回验。
3. 在原文件旁用唯一名称创建旧库备份，刷新到磁盘并逐字节验证与读入的旧文件一致。
4. 获取旁路 `.json.lock` 文件的操作系统文件锁，再次比较当前磁盘字节与本次读取版本。不同则拒绝提交，避免覆盖其他 Adit 进程或同步软件刚写入的库。
5. 创建同目录临时文件并刷新。在 Windows 使用 MoveFileExW(REPLACE_EXISTING | WRITE_THROUGH)，在 Unix 使用 rename 并刷新目录。失败时保留原文件，成功后更新缓存。

这个锁协调遵守同一协议的 Adit 进程；第三方同步软件可能不遵守建议锁，不能将其当作跨机器分布式事务。缓存检测到文件替换时立即丢弃旧密钥并重新锁定；已经打开过的文件被删除时返回冲突，不静默新建 v1 空库。

**v1 迁移备份仍使用原来的弱保护。** 启用主密码不改变已经导出、云端留存、版本历史或回收站中的旧文件。应由用户确认可恢复性后自行处理旧副本；程序不自动删除它们。文件权限仅能限制正常本机用户访问，不能代替加密。

## 导出、导入与回退

导出只复制加密文件，不导出主密码；目标必须不存在，避免意外覆盖备份。锁定状态也允许导出密文。导入先验证源文件的主密码、校验项和全部条目，再验证当前库允许修改，备份当前库，最后原子替换。源库或目标库的主密码错误时不修改当前库。导入 v2 后保持锁定，使用源文件主密码解锁。

导入是整库替换，不是按密码合并。profile 目录仍需单独导出/同步，账号标识必须相符。回退可通过“导入加密凭据”选择迁移时产生的备份；v1 备份不需要源主密码，v2 备份使用备份创建时的主密码。旧版 Adit 不理解 v2，不能通过运行旧版来完成回退。

忘记主密码没有恢复后门。只有掌握主密码的加密备份或其他仍可用的认证来源才能恢复密码。重新创建空库会丢弃保存的秘密，应先保存原密文，不能把它作为“解锁”操作。

## 云同步

主密码和解锁密钥不进入同步文档。凭据作为不透明的密文整库保存，不能逐条合并。当前实现允许首次备份和两端字节相同的情况；当本地、云端都存在且内容不同时直接拒绝覆盖，也拒绝隐式 v2 → v1 降级。错误信息要求先导出备份、显式导入要保留的库，或关闭凭据同步。关闭凭据同步时，上传配置不会删除已有云端密文。

这是保守的备份/冲突处理语义，不是多设备密码库自动合并。同步目录中的外部替换仍需在本机重新解锁。配置、普通应用设置的合并策略独立于主密码。

## 自动验证入口

`cargo test -p adit-storage -p adit-sync` 验证迁移备份字节一致、模拟 SSH/RDP/VNC 三个账号的密码保留、重启锁定、错误主密码、修改/关闭保护、外部文件替换/删除、导出/导入、账号密文交换拒绝和云端冲突拒绝。测试只使用合成秘密。

这些存储测试不能代替真实桌面上的设置交互验收，也不能证明所有 SSH 认证方式和远端桌面服务端已经兼容。完整 CI 和各协议实连结果应附在对应 Issue。
