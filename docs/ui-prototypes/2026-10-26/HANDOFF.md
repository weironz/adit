# 已选 D / E / F 的 UI 重构交接

## 接手目标

在保持 Rust/iced 技术栈和现有连接能力的前提下，改进 Adit 的资源管理、会话切换和视觉一致性。

核心结果：

1. 保存的主机资源与已打开会话是不同概念；在任一视图内，侧栏和主区域不再同时完整列举同一份主机目录。
2. 多会话不再迫使顶部标签无限增长，隐藏导航项不能导致连接被关闭。
3. 参考 Termius 的深蓝灰表面、彩色主机图块、轻边界和清晰层级，保留 Adit 身份与已有明暗主题。
4. 保留现有 SSH、SFTP、RDP、VNC、本地 shell、串口、Telnet、凭据与输入行为。

## 设计决策状态

用户已明确表示“我要选 DEF”，并要求清理旧候选、更新交接提示词。**D/E/F 是已选定的完整方案，不再是等待确认的建议。**

本次应实现 **D 的资源入口 + E 的专注工作区 + F 的任务分屏视图**。F 不能降为可选或推迟为“未获批准的候选”。任务组织默认先复用现有会话与分屏能力，在本次运行内管理；选择界面不等于授权额外的工作区持久化、自动恢复、团队权限或协作后端。

不需要为了例行的可逆实现选择反复要求用户配合。涉及改变上述产品边界时，应说明影响，并与用户对齐。

## 原型怎样映射到产品

### D：资源入口

- 左侧为功能导航或分组导航，不再次展示完整的主机行列表。
- 主区域为唯一的主机卡片/列表，可搜索、筛选分组，并按需展示详情。
- 打开已连接主机时要区分“切换到既有会话”和现有“新建另一会话”的行为，不要默默删除多开能力。
- 原型中的“本地资源库”是导航措辞，不代表必须引入新的多 Vault 数据模型。

### E：日常工作区

- 左侧仅列已打开会话；不能把所有保存配置重新塞进来。
- 主区域展示活动终端或远程桌面。
- 顶部保持少量全局入口和当前上下文，不为所有连接建立横向标签。
- 提供可达的查找/切换入口，切换不会关闭其他连接。
- 侧栏隐藏后仍有可发现的恢复与会话切换入口。

### F：任务分屏视图

- 左侧按任务组织打开的会话；主区域展示该任务的实际窗格，不重新列举完整主机目录。
- 支持任务切换、聚焦单窗格和返回分屏；切换任务或隐藏窗格不关闭连接。
- 任务名称和成员来自运行期的真实会话组织，不得把原型的三组固定样本硬编码进产品。
- 复用现有分屏及会话生命周期。若混合 SSH/RDP/VNC 窗格需要调整渲染状态，应先列出受影响路径并分步迁移，不能复制同一帧冒充不同主机。
- 本次包含 F 的可用视图和运行期组织；工作区持久化、恢复和协作需另行明确范围。

## 实施建议

按小步改动交付，不要一次重写整个 UI：

1. 提取或补齐语义 token 与基础组件：字体层级、间距、密度、主次按钮、输入、列表行、菜单、弹层、选中/焦点/禁用/错误状态。沿用已有样式基础。
2. 改造资源页及导航职责，保留已有配置、分组、固定、最近连接和拖放行为。
3. 改造打开会话的导航及工作区外壳，保持连接生命周期、输入和渲染路径。
4. 实现 F 的任务组织、实际分屏、聚焦与返回，复用已有会话，不引入无关后端能力。
5. 根据实际需要整理屏幕局部状态和消息，避免继续扩大全局状态；不要求为追求形式而全量替换 Message 或引入新架构框架。

每步给出可运行界面和实际截图，再继续受影响的部分。将功能进度记录在 GitHub Issues，避免创建平行路线图。

## 必须保住的边界

- **这是原生 UI 重构。** HTML/CSS/JS 是设计参考，不是要迁回 Tauri、React、WebView 或 Flutter；不把网页原型的 DOM 重建方式搬入生产架构。
- **视觉去重不等于删除数据或能力。** 保留 ProfileId/SessionId、分组顺序、固定顺序、最近连接、多选、拖放及配置兼容性。
- **导航切换不改变连接归属。** 原型里的隐藏与显示不能被翻译为关闭、重连或重建真实会话。
- **输入路径是高风险区。** 调整侧栏、标签高度、边距或分屏几何时，同步核对终端与 RDP/VNC 的坐标、缩放和命中测试。
- **快捷键必须按上下文路由。** 原型的 `Ctrl K` 只是演示。不能无条件抢走 SSH、远端桌面、文本框、IME、全屏或抓取模式中的组合键。保留 Ctrl/Cmd、AltGr、系统键归属与持键释放约束。
- **焦点切换必须可靠。** 弹层打开后的初始焦点、Tab 循环、Esc 关闭、返回原控件以及远端输入暂停都需要明确验证。
- **避免恢复旧画面的交互。** 连接错误和非 Connected 状态下，具体错误必须可见；不得让陈旧画面遮住错误或继续接收远端输入。
- **不阻塞 UI 线程。** 文件写入、凭据迁移、网络、握手及 helper 启动维持已有后台路径。
- **RDP helper 仍为独立 workspace/进程。** 不更换协议栈，不为 UI 调整升级 russh/IronRDP 或改变 IPC。
- **不要把演示数据做成产品事实。** 原型的在线点、42 ms、CPU/内存、日志和桌面均是合成内容，不能硬编码到真实产品或宣称服务器健康。
- **不读取或提交真实凭据。** 不读取含密钥的本地构建配置，不将地址、密码、剪贴板或远端桌面上传到原型工具。
- UI 文案遵循现有中文与 `i18n` 约定，保留既有语言选项。

## 验收要求

### 行为

- 资源页与工作区各有清楚职责；没有并排完整重复的主机清单。
- D/E/F 三个视图均可达；F 的任务切换、实际分屏和聚焦/返回可用，不作为可选项遗漏。
- 至少用 12 个合成打开会话验证导航，隐藏连接不被断开，活动会话可找到。
- 主机搜索、分组、固定/最近连接、编辑、保存和认证失败原标签重试保留。
- 侧栏收起、展开、窗口变小、窗口恢复、分屏与全屏后，点击与远端坐标保持正确。
- 对普通窗口和 Windows 100%/150%/200% 缩放记录实际验证范围；原型的 390px 浏览器布局不等于原生 DPI 已通过。
- SSH 输入、复制粘贴、终端选择/滚动与 RDP/VNC 键鼠、只读、IME、系统键保持正确归属。
- 连接中、取消、空、部分失败、错误、重试和只读状态均有清晰可操作的反馈。
- 保留明暗主题、可见焦点与文字对比；不能只靠颜色表达错误或选中。

### 工程验证

- 按 `AGENTS.md` 执行必要的构建、Clippy 和测试；Rust 改动至少执行 `just ci`，输入/远程桌面路径变更按需执行 `just ci-vnc` 和相关定向回归。
- `adit-rdp` 是独立 workspace；根工作区测试不能代替 helper 检查。
- 正式 CI 只使用仓库指定的 Windows/Linux x64 自托管 runner。ARM64/macOS 和额外发布平台继续停用，不启用托管 runner。
- 不发布版本，不 bump/tag，不安装覆盖用户日常应用，除非另有明确授权。
- 报告实际执行、通过、失败、忽略和未验证项；浏览器原型通过不等于原生产品验收通过。
- 尽量使用自动化与已有隔离夹具；真实环境不可用时单列未验证范围，不要求用户反复辅助，也不以替代测试冒充通过。
